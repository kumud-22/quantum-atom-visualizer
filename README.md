# Quantum Atom Explorer

A web application for a science exhibition that explains the quantum mechanical model of the atom using an interactive 3D visualization.

## Features

- Rotatable and zoomable 3D atom built with Three.js
- Nucleus with protons and neutrons
- Probability-based electron cloud and orbital visualization
- Shells, subshells, and orbital selection
- Quantum numbers panel and explanation of allowed values
- Element selector with common elements and electron configurations
- Interactive educational notes and explain-this system
- Exhibition mode with guided tour and automated orbital highlights
- Quality setting for low, medium, and high performance
- Responsive layout for desktop, tablet, and mobile devices

## Scientific concepts demonstrated

- Quantum mechanical model vs. outdated Bohr planetary model
- Electron probability distributions and orbitals
- Shells and principal quantum number n
- Subshells (s, p, d, and f)
- Pauli exclusion principle
- Aufbau principle
- Hund's rule
- Heisenberg uncertainty principle
- Electron configuration notation such as 1s² 2s² 2p⁶

## How to run locally

1. Download or clone the project files.
2. Open `index.html` in a browser.
3. The application works as a static front-end without a backend.

## How to deploy using GitHub Pages

1. Create a new GitHub repository.
2. Upload these files to the repository root:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
3. In GitHub, open the repository and select:
   - Settings
   - Pages
   - Source: Deploy from a branch
   - Branch: `main` or your default branch
   - Folder: `/root`
4. Save the settings.
5. GitHub Pages will provide a public URL for the project.

## Educational disclaimer

This visualization is a conceptual educational representation of quantum probability distributions and does not depict electrons as literal photographs or fixed tracks. It shows orbitals as probability regions used in modern quantum mechanics, which are mathematical descriptions of electron behavior rather than physical paths.

## Project title

Quantum Atom Explorer

## Description

This project demonstrates the structure of an atom according to modern quantum theory. It highlights the nucleus, shells, subshells, orbitals, electron clouds, and electron configuration in a visually engaging and scientifically accurate educational interface.

## Scientific disclaimer

The model is intentionally simplified for classroom use. It uses probability-density-inspired orbital shapes to communicate quantum behavior clearly while avoiding the incorrect idea that electrons orbit like planets.
